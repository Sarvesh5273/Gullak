Gullak TESTNET DEMO

Gullak for Android

A family money pot. Sign in with a passkey, hold dollars, and send them to family in about a second, with no network fees to pay.

This is a hackathon demo on Monad testnet. No real money moves.
  • Balances are test dollars (AUSD on Monad testnet) with no cash value.
  • “Add money” hands out test dollars. “Send to UPI” settles on testnet, but no rupees are paid out.
  • Rupee amounts are indicative, from daily public exchange rates.

You’ll need

  • An Android phone running Android 9 or newer, with Google Play services.
  • A screen lock (fingerprint, face, PIN or pattern) and a Google account on the phone. Your passkey is saved in Google Password Manager.
  • A 64-bit ARM phone (nearly every current phone). x86 emulators and old 32-bit phones can’t install it.

Install

  1. Tap Download APK on this page, on the phone. Chrome may warn that the file might be harmful. Tap Download anyway.
  2. Open the file. Tap the download notification, or find gullak.apk in Files › Downloads.
  3. Allow installs from your browser if Android asks: tap Settings, turn on Allow from this source, then go back. You can switch this off again after installing.
  4. Tap Install. Google Play Protect may say it doesn’t recognise the app, because it isn’t from the Play Store. Tap More details, then Install anyway. If it offers to scan the app, that’s fine too. If Android says “App not installed”, uninstall any older Gullak test build first, then try again.
  5. Open Gullak.

Try it

  1. Create your account with a passkey (your screen lock) and pick an @handle. No password, no seed phrase.
  2. Add money. Choose $10 and confirm. Test dollars land in a few seconds.
  3. Send to an @handle. To see both sides, open the web app on a computer or another phone, create a second account, and send between the two.
  4. Send to UPI. Send to any UPI ID. It settles on testnet; the rupee payout itself is simulated.

Every receipt links to the transaction on the Monad testnet explorer. Daily limits protect the shared test budget, so if something says it’s paused, try again later.
